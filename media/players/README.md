# İzinli oyuncu fotoğrafları

Yalnızca kullanım izniniz olan gerçek Beşiktaş formalı/antrenman kıyafetli fotoğrafları yükleyin. Miretti fotoğraflarını `media/players/miretti/` klasörüne JPG, PNG veya WEBP olarak koyun. Klasördeki her dosya Miretti'ye ait ve izinli olmalıdır; bot fotoğraftaki kişiyi otomatik doğrulamaz.

Başka oyuncular için `media/players.json` içine name, aliases ve folder kaydı ekleyin. İsim/soyisim eşleşmesi haber başlığında aranır. Birden fazla oyuncu eşleşirse katalogdaki ilk oyuncu seçilir. Fotoğraflar başarılı Instagram paylaşımlarına göre dönüşümlü kullanılır; tek fotoğraf varsa aynı fotoğraf tekrar kullanılır. Oyuncu havuzu boşsa ilgisiz stadyum fotoğrafı gönderilmez. Genel takım haberlerinde mevcut AI/CC0 yedek görsel akışı sürer.
